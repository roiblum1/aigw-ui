# 0.2.0 (2026-10-07)

## New

- **Discovery through the gateway.** A cluster can be given a Gateway URL.
  Model names are then read from the gateway's own `/v1/models`, which covers
  routes in every namespace and every backend type. The `AIGatewayRoute`
  objects attached to the gateway are scanned in all namespaces to find the
  `AIServiceBackend`s each model is served from. An optional API key for
  `/v1/models` is stored encrypted. Without a Gateway URL, discovery scans
  the gateway namespace as before.
- **Quotas next to their backends.** A `QuotaPolicy` can only target backends
  in its own namespace, so one policy is now created per namespace that holds
  a backend of the model.
- **Models without a quota target are shown, not dropped.** A model the
  gateway lists but that has no `AIServiceBackend` (for example one served
  from an `InferencePool`) appears with "no quota possible", and the API
  refuses a quota on it. A backend whose route sets no `modelNameOverride`
  is marked "quota unverified".

## Changed behaviour

- With a Gateway URL set, a failed call to either source fails the whole
  poll and changes nothing, so quota policies already in place are not
  removed by a partial answer.

## Upgrade

Migration `003_gateway_url.sql` adds `clusters.gateway_url` and
`clusters.discovery_token_enc`.
