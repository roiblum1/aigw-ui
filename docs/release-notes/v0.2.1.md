# 0.2.1 (2026-10-07)

## Fixes

- **"Failed to add finalizer" on every QuotaPolicy reconcile.** The gateway
  controller writes each `QuotaPolicy` back with an empty `serviceQuota` when
  none is set, and the CRD rejects the empty duration
  (`spec.serviceQuota.quota.duration: Unsupported value`). Every policy now
  carries a `serviceQuota` of 4294967295 tokens per second. The gateway does
  not enforce the field today, and the value means "no limit" if it ever
  does.

## Upgrade

Existing policies are corrected by the first sync after the upgrade. Press
**Sync all** on the Clusters page to do it at once.

## Not verified on a real gateway

That the error stops. The fix follows the CRD and the controller's types but
was not run against a live controller.
