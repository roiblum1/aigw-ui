# 0.1.1 (2026-10-07)

First release.

- **Clusters**: register LLM clusters by kubeconfig, test the connection,
  preview the manifests, sync on change. Kubeconfigs and API keys are stored
  encrypted (AES-256-GCM) in Postgres.
- **Models**: discovered every minute from each cluster's `AIGatewayRoute`
  objects, or added by hand with a `Backend`, `AIServiceBackend` and
  `AIGatewayRoute` created for them.
- **Tenants**: one per team, with API keys that are issued and revoked, and
  enforced by a `SecurityPolicy` on the gateway.
- **Quotas**: a token budget per tenant per model, per minute, hour or day,
  rendered as a `QuotaPolicy`. All keys of a tenant share one bucket.
- **API**: everything the UI does, over REST with a bearer token.
- **Deployment**: UBI9 image, Helm chart for OpenShift (restricted-v2 SCC,
  edge-TLS Route, NetworkPolicy), and an offline bundle for disconnected
  environments.

0.1.1 differs from the unpublished 0.1.0 in one fix: the server waits up to
two minutes for Postgres at startup instead of crash-looping on a fresh
install.
