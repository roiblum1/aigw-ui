# 0.22.0 (2026-10-16)

A tenant's budget across every priced model, enforced by the gateways: one
amount in dollars per minute, hour or day for all models together, which a
cheaper model spends more slowly. And the models a tenant may call: any
other is refused before a model or a quota is asked. Both are what the
[design](../design/capacity-prices-wallets.md#identity-and-quota-rules)
meant by step 5c once the gateway could enforce it; the hub-enforced wallet
of 0.20.0 was removed in 0.21.0.

Database: migration 025 adds a tenant's budget, whether it is held to some
models, and the table of those models.

## Upgrading

Nothing changes on the gateways until a tenant is given a budget or a list
of models. Both need every tenant on tokens, as a standard budget does.

A budget across models needs **global rate limiting enabled in the Envoy
Gateway configuration of every cluster**, with the Redis the gateways share and a
timeout of a few seconds; Envoy Gateway then runs its own rate limit
service next to the AI gateway's. See
[deployment](../deployment.md#before-the-first-budget-across-models). The
sync reports the budget policy's `Accepted` condition, and the self-test's
new step fails while anything on the path is missing.

A budget across models is counted and enforced by the gateway; the hub only
renders it. Two things follow: a request passes where a cluster cannot reach
the shared Redis, and changing a tenant's budget starts its count over for
the running period. The owner accepted both.

## What changed

- **Budget across models**, on a tenant's page and in the Tenants list.
  One `BackendTrafficPolicy` per cluster, `aigw-ui-tenant-budgets`, with one
  shared global rate limit rule per tenant on `x-aigw-tenant`, a request
  cost of 0 and a response cost from the credits the model's route writes.
  Every cluster renders the same policy and counts in the same key of the
  Redis the gateways share, so a tenant has one budget wherever its requests land. The
  tenant's quotas per model hold alongside it. Models without prices are
  not in it; the page says which.
- **Every route of a priced model writes what a request cost in credits**
  (`llmRequestCosts`, key `aigw_ui_credits`): the routes the hub renders
  carry it, and the sync puts it on a route a cluster's own chart renders,
  next to the quota revision, keeping any other cost the route has.
- **Models a tenant may call**, on a tenant's page: every model, or a list.
  One `Deny` rule per such tenant in the `SecurityPolicy`, on the tenant
  header and the model header the gateway sets; any other model gets 403,
  also one added later.
- **Usage:** the Usage page and a tenant's page show what each tenant used
  of its budget across models; the tenants' own page shows the tenant's
  budget, what is left and whether a gateway holds it to it.
- **Self-test:** "A budget across models is counted and refuses" and "A
  tenant held to its models is refused for any other", last before the
  cleanup. The sync reports a `BackendTrafficPolicy` the gateway's
  controller does not accept, as it does a patch.
- **API:** `PUT /tenants/{id}/budget`, `PUT /tenants/{id}/models`; a tenant
  has `budget` and `models`; `GET /usage` has `budgets`; `GET /my/usage`
  has `budget`. Both PUTs answer 409 while the gateways take API keys too,
  and an API key cannot be created while any tenant has a budget or a list.

## Tested

- **Units and store, on Postgres:** the rendering of the policy, the route
  costs, the annotation for a chart's route, the counter names as the hub's
  Redis named the lab's, the model rules, and that nothing is rendered
  without tokens only; the store round trip and the render state; the
  sync's status reading; the API server tests; the UI type check and tests.
- **On the lab before the build** (2026-10-16, on a listener of its own
  with stand-in models): the same policy shape held tenant-x to $1 and
  tenant-y to $3 across opus and sonnet with 429 on the next request after
  each, a tenant without a rule was not held, the allowlist refused with
  403 before any quota, a forged tenant or model header was overwritten,
  and a cost of 20,000, 60,000 and 300,000 micro-dollars for the same
  prompt on haiku, sonnet and opus matched the prices exactly. The
  gateway's check against the shared Redis (the sandbox hub's, on the lab) added about 31 ms to a request at
  the median and about 60 ms at the 99th percentile from the lab.

## Not tested

- **The hub's own rendering on a gateway:** the lab check applied the
  policy by hand. After the merge the sandbox hub syncs the lab and the
  self-test's two new steps check the whole path, including the CEL rule
  for the models, which the lab check did with header principals instead.
- **A route a cluster's own chart renders:** that the sync's patch of its
  `llmRequestCosts` is kept by the chart's own reconciler. The lab's model
  has an entry route the hub renders.
- **Parallel requests at the limit:** a tenant can go past its budget by
  every request in flight when it is reached; the lab sent requests one at
  a time.
