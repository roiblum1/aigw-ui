# 0.5.7 (2026-10-08)

## Fixes

- **Chart legends no longer run out of their panel.** With a long tenant or
  model name, the number next to it was pushed past the edge of the panel
  and cut off. The name is now shortened with an ellipsis instead, and the
  full name shows on hover.

## Upgrade

No migration and no setting to change.
