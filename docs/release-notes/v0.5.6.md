# 0.5.6 (2026-10-08)

## Fixes

- **The Overview said nothing when there was nothing to chart.** The "Token
  usage right now" card was hidden until a tenant quota existed, so a fresh
  install looked as if the charts were missing. The card is now always
  there: it says that no quota exists yet, or that usage monitoring is off
  and how to turn it on.

## New

- **`hack/seed-demo.py`** fills an instance with demo clusters, models,
  tenants and quotas named `demo-*`, and writes made-up usage into Redis for
  a few minutes, so the Usage page and the Overview charts can be shown
  without a real gateway. `--clean` removes the demo data again. It is for
  demos and tests only: the numbers are invented.

## Upgrade

No migration and no setting to change.
