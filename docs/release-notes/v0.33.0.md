# 0.33.0 (not released yet)

A model's pool keeps its counter when the model's quotas change. The AI
gateway names the pool's counter after the number of rules in the model's
`QuotaPolicy`, and that number followed the positions in use: an amount
added after the last one, the last one freed, or the first budget across
models on the model started the pool's window again. Every `QuotaPolicy`
now has a multiple of eight rules, with placeholders after the positions in
use, so the name changes only when they cross a multiple of eight.

Database: no migration.

## Upgrading

- **Every pool's counter is renamed once**, at the first sync after the
  upgrade: from `rule-<positions in use>` to `rule-8` (`rule-16` for a model
  with nine to sixteen positions). Each pool counts from 0 for the rest of
  its running window, so the tenants on a pool can use up to twice the pool
  in that window. Tenants' own quotas and budgets are not affected: their
  rules keep their positions and their counters.
- **Every model's routes are built again once.** The quota revision
  (`gateway.envoyproxy.io/aigw-ui-quota-revision`) now holds the number of
  rules, so it changes for every model at the upgrade, also where no quota
  changed, and Envoy Gateway builds the routes with the pool's new entry.
- **The best-effort route's policy** gets eight rules even on a model
  without quotas. Its pool was read under `rule-0`, a key the gateway never
  writes for a policy with no rule (AI Gateway names that pool without a
  rule number); the Usage page now reads it where the gateway counts it.
- The Models page and `GET /models` `rules` still give the positions in use,
  without the placeholders.

## Changed

- **A `QuotaPolicy` has a multiple of eight bucket rules.** The positions
  in use come first, as before; placeholders, which match no request, fill
  the rest. The pool's counter is named after the total, so it stays the
  same while a model has up to eight positions in use, then up to sixteen,
  and so on. Eight and not more: each rule, a placeholder too, is an entry
  in every route of the model, and at 256 rules a change took 11 to 19
  seconds to reach the proxy (lab, 2026-10-16). A placeholder adds 148 bytes
  to the `QuotaPolicy`: 1,871 bytes for a model with three positions in use.

## Fixed

- **A model's pool let more than its limit through after a quota change**
  (lab, 2026-10-17: a pool of 20 credits an hour counted under rules 5, 10
  and 11 within one hour and let 78 through). What a pool let through
  before the upgrade is not taken back.
- The best-effort route's pool on a model without quotas was read from a
  key that does not exist.

## Tested

On 2026-10-18:

- `go test -race ./...` with Postgres 17 and Redis 7. New:
  - the pool's key stays the same when an amount is added after the last,
    the last is freed, the first budget across models comes and the last
    goes, and becomes `rule-16` at the ninth position
    (`TestPoolKeepsItsCounter`);
  - the same with a rule per tenant, while API keys are taken
    (`TestPoolKeepsItsCounterWithARulePerTenant`);
  - the best-effort route's pool keeps its key when the model gets its first
    quota (`TestBestEffortPoolKeepsItsCounter`);
  - the quota revision differs from the one 0.32.1 made for the same
    quotas, and changes at the ninth position
    (`TestQuotaRevisionHoldsTheRuleCount`).

  The first three fail with 0.32.1's rule count and pass with this one.
  The tests that pinned whole rule lists now expect the placeholders.
- `hack/test-apiserver.sh` (Envoy Gateway v1.9.2 and Envoy AI Gateway
  v1.2.0 CRDs) and its v1.9.1 / v1.1.0 variant: both take the padded
  policies, by amount and with a rule per tenant, and store the
  placeholders as rendered.
- In the source of Envoy AI Gateway v1.1.0 and v1.2.0, the pool's descriptor
  key is `DefaultBucketDescriptorKey(len(BucketRules))`, placeholders
  included, both in the rate limit configuration
  (`internal/ratelimit/translator/translator.go:267`) and in the route
  (`internal/extensionserver/quota_ratelimit.go:608`); a policy with no rule
  names its pool without a rule number (`translator.go:222`).

Not run:

- Anything on a gateway: that the pool is counted under `rule-8` after the
  upgrade and keeps that key when an amount is added (end-to-end check 4),
  and how much the placeholders add to the proxy's route configuration and
  to the time a change takes to reach the proxy.
