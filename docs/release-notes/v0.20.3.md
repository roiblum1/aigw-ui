# 0.20.3 (2026-10-15)

A fix to the self-test, found on the lab once its gateway counted in the
hub's Redis and took tokens only.

No database change.

## Fixed

- **The self-test's `counter` step warned on a correct count.** The
  `revoked-token` step ran just before it. While it waits for the gateway to
  take the tenant's second token, its requests meet the tenant's spent quota,
  and each refused request adds 1 to the counter. The lab counted 316 for a
  request of 314 tokens, where the step allows 315. The `revoked-token` step
  now runs after every step that reads the counter.
- `docs/api.md` lists every step ID, in the order they run.
