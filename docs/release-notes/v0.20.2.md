# 0.20.2 (2026-10-15)

Two fixes found by the self-test on the lab, once its gateway took tokens
only.

No database change.

## Fixed

- **A revoked token could work again for up to a minute after it expired.** A
  gateway takes a token up to 60 seconds past its expiry: Envoy allows that
  much for the clocks of the hub and the gateway to differ, and Envoy Gateway
  has no setting for it. The hub dropped a revoked token's deny rule at the
  expiry itself, so for that minute the token could be taken again. The rule now
  stays until five minutes after the expiry.
- **The self-test's expired token was not expired enough.** It had expired a
  minute before it was sent, inside the same allowance, so a gateway that
  takes tokens only took it now and then, and the `bad-key` step failed. It
  now expired ten minutes before. While a gateway also takes API keys, the API
  key check refused it anyway, which is why the step passed until then.
