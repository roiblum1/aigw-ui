# 0.7.1 (2026-10-09)

## Changed

- **The image moved from Docker Hub to the GitHub Container Registry.** It is
  now `ghcr.io/roiblum1/aigw-ui:<version>`, built and pushed by the GitHub
  workflow from the tagged commit. The chart, the offline bundle script and
  the documents all use the new name. Nothing else changed since 0.7.0.

  0.7.0 and older stay on Docker Hub as `docker.io/roi12345/aigw-ui`; no new
  version is pushed there.

## Upgrade

```sh
helm upgrade aigw-ui deploy/chart/aigw-ui -n aigw-ui
```

- **If you set `image.repository` yourself**, or upgrade with
  `--reuse-values` after having set it, change it to
  `ghcr.io/roiblum1/aigw-ui` or remove it.
- **The cluster must be able to pull from `ghcr.io`.** If the package is
  private, create a pull secret from a GitHub token with `read:packages` and
  name it in `global.imagePullSecrets`.
- **Disconnected installs:** with `global.imageRegistry` set, the image is
  now pulled from `<registry>/roiblum1/aigw-ui`, where it used to be
  `<registry>/roi12345/aigw-ui`. Build a new bundle with
  `deploy/offline/build-bundle.sh` and load it; `load-images.sh` pushes to
  the new path.

## What was tested

The chart renders the new image name. The image itself is built by the
workflow run of this tag; its result is on the repository's Actions page.
