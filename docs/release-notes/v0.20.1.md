# 0.20.1 (not released yet)

A fix found while testing 0.13 to 0.20 on the sandbox hub and the lab.

No database change.

## Fixed

- **A hub not allowed to list LLMInferenceServiceConfigs said nothing.**
  The spec hash of a measurement (0.16) then held the configs' names only,
  so a change in a preset or a shared config, such as a scheduler upgrade,
  did not mark the measurement stale. The sandbox hub was in that state. The
  cluster's discovery message now says so, next to the note about pods and
  nodes it may not list.
- **The 0.16 upgrade notes** now name the permission a hub with narrow
  credentials needs: get and list on
  `llminferenceserviceconfigs.serving.kserve.io`, cluster-wide.
